C Shark Kft. - Ügyfélszolgálati Portál
Ez a weboldal az Óbudai Egyetem (ÓE-NIK) Operációs rendszerek kurzusára készült féléves feladatként.
Fontos megjegyzés: Ez egy fiktív weboldal, egy kitalált informatikai cég bemutatkozó felülete. A megadott adatok, telefonszámok és helyszínek kizárólag a feladat szemléltetésére szolgálnak.

Design és megvalósítás:
A projekt során külön figyelmet fordítottam a vizuális megjelenésre, amelyet tisztán HTML és CSS segítségével értem el. 
A bal felső sarokban látható "C Shark Kft." felirat nem képfájl, hanem egyedi CSS formázás eredménye. Speciális betűtípus-beállításokkal és stílusokkal alakítottam ki a logoszerű hatást. 
Az adatok (nyitvatartás, elérhetőségek) átlátható, kártyaszerű elrendezést kaptak.

Alkalmazott technológiák:
- HTML5: Szemantikus kódfelépítés.
- CSS3: Egyedi tipográfia, elrendezés és a logoszerű felirat stílusa.
- Google Maps API: Beágyazott térkép a helyszín szemléltetéséhez.

Tartalom:
- Részletes nyitvatartási és ügyfélfogadási táblázatok.
- Közvetlen kapcsolati adatok (email, telefon).
- Tájékoztató a parkolási lehetőségekről és a tömegközlekedésről.
