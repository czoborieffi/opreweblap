### 💡 Overview

University coursework project implementing a fictional client service web portal for *C Shark Kft.* The application showcases custom frontend architecture and interactive UI components designed entirely without external frameworks.

---

### ✨ Core Features

* **Interactive Cost Calculator:** A built-in web tool allowing visitors to select services, specify units, and calculate preliminary budget estimates.
* **Dynamic Quotes & Support:** Seamless contact options including direct inquiry submission and detailed customer service hours.
* **Location Integration:** Customer support information paired with public transport details and an embedded Google Maps view.

---

### 🎨 Design & Implementation

* **Custom CSS Logotype:** The top-left brand header (*C Shark Kft.*) is styled purely through advanced CSS rules rather than static image assets.
* **Card-Based Layouts:** Information grids, opening hours, and service overviews are structured into clean, scannable cards.
* **Modular Structure:** Built using semantic HTML5 elements, dedicated stylesheets, and separated page views.
